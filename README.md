# Biotech Learning Journal — BioGene Studio

Building foundational computational biology tools and tracking Python progress.

 Week 1: DNA Sequence Analyzer & Toolkit
- Key Concepts Learned: String manipulation, immutability, methods (.count(),.replace(),.upper()), string slicing ([::-1]).
- Scripts Built:
  - Day 2 Basic DNA Sequence Analyser.py: Base composition & complement calculation.
  - Day 4 Debugging DNA Sequence.py: Fixed syntax, name, and logic errors.
  - week_1_dna_toolkit.py: Full interactive DNA analyzer (GC-content, complements, RNA transcription, and reverse complement).
  - Day 8: Used range(0, len(seq), 3) to slice mRNA into triplets, mimicking ribosome reading frames and filtering incomplete trailing bases.
  - Day 9: Used a dictionary (.get()) for codon-to-amino-acid lookups, using break to stop translation at biological STOP codons (UAA, UAG, UGA).
